MCP · Kết nối công cụ bên ngoài

Một MCP server local dùng chung account OAuth của extension. Chọn server ChatGPT hoặc Antigravity trong client; không cần cài extension ở project bên kia.

Trạng thái credential trên máy này
Chỉ đọc email/trạng thái đã lưu, không hiển thị access token hoặc refresh token.
Chưa kiểm tra
Hai cấu hình provider
ChatGPT
Dùng account ChatGPT OAuth hiện có. Giữ tương thích với lệnh MCP cũ nếu không truyền provider.
claude mcp add --scope user aigpt-chatgpt --env AIGPT_MCP_PROVIDER=chatgpt -- uv run --project C:/path/to/chatgptimage aigpt-mcp
Antigravity
Dùng account Google Antigravity OAuth và quota riêng. Hỗ trợ model, 1K/2K, tạo/sửa/ghép ảnh.
claude mcp add --scope user aigpt-antigravity --env AIGPT_MCP_PROVIDER=antigravity -- uv run --project C:/path/to/chatgptimage aigpt-mcp
Claude Desktop, Cursor, VS Code, Windsurf

Thay C:/path/to/chatgptimage bằng đường dẫn thật, hoặc chạy script để tự lấy đúng đường dẫn trên máy này.

{
  "mcpServers": {
    "aigpt-chatgpt": {
      "type": "stdio",
      "command": "uv",
      "args": ["run", "--project", "C:/path/to/chatgptimage", "aigpt-mcp"],
      "env": { "AIGPT_MCP_PROVIDER": "chatgpt" }
    },
    "aigpt-antigravity": {
      "type": "stdio",
      "command": "uv",
      "args": ["run", "--project", "C:/path/to/chatgptimage", "aigpt-mcp"],
      "env": { "AIGPT_MCP_PROVIDER": "antigravity" }
    }
  }
}
Cấu hình này là stdio: client tự khởi chạy process MCP và giao tiếp qua stdin/stdout.
Tự sinh config theo đường dẫn hiện tại
powershell -ExecutionPolicy Bypass -File scripts\gen_mcp_config.ps1 -WriteMcpJson
Chạy trong repo này; script sẽ in lệnh Claude Code và ghi .mcp.json vào thư mục hiện tại nếu dùng -WriteMcpJson.
API key / OAuth
MCP local vẫn dùng OAuth ChatGPT/Google đã đăng nhập. API key là lớp xác thực tùy chọn cho client MCP yêu cầu credential riêng; key này không thay thế và không chứa access/refresh token.
Chưa tạo API key.
Key chỉ hiện đầy đủ một lần. Hãy copy và lưu vào password manager.
AIGPT_MCP_API_KEY=<dán key vừa tạo>
Đặt biến này trong env của MCP client. Khi có biến này, process MCP sẽ từ chối key sai.
Không copy access token hoặc refresh token vào MCP config. Nếu không tạo API key, stdio local vẫn hoạt động như trước.
Tools hiện có

  • list_image_models — xem model GPT Image 2 hoặc danh sách model ảnh Antigravity hiện có.
