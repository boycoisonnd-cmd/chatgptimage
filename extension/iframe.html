🔌 Nối project khác vào MCP server này

Repo này có sẵn một MCP server (aigpt-mcp) — bất kỳ công cụ nào hỗ trợ MCP (Claude Code, Claude Desktop, Cursor, VS Code, Windsurf…) đều gọi được để tạo ảnh bằng các account ChatGPT đã đăng nhập ở đây. Bên kia không cần cài extension.

Cách hoạt động
  • Ảnh được tạo qua backend web ChatGPT (không phải OpenAI API chính thức, không cần API key).
  • Cần ít nhất 1 account ChatGPT đã đăng nhập — bấm Thêm account trong panel này, hoặc chạy uv run aigpt login --wait.
  • Account dùng chung giữa panel / CLI / MCP — đăng nhập 1 lần là đủ cho mọi client.
Bước 1 · Lấy config đúng cho máy này

Chạy script bên dưới trong thư mục repo — nó tự tìm đường dẫn repo, không hardcode, nên đúng cả khi bạn chuyển repo sang máy khác đặt vị trí khác. Copy output rồi dán vào client MCP của bạn.

powershell -ExecutionPolicy Bypass -File scripts\gen_mcp_config.ps1
Chưa muốn chạy script? Các ví dụ bên dưới dùng đường dẫn mẫu C:/path/to/chatgptimage — nhớ thay bằng đường dẫn repo này trên máy bạn.
Bước 2 · Claude Code (từ folder project khác)
claude mcp add aigpt -- uv run --project C:/path/to/chatgptimage aigpt-mcp
Rồi kiểm tra: claude mcp list — và thử "generate an image".
Bước 3 · Claude Desktop
{
  "mcpServers": {
    "aigpt": {
      "command": "uv",
      "args": ["run", "--project", "C:/path/to/chatgptimage", "aigpt-mcp"]
    }
  }
}
Sửa claude_desktop_config.json (Claude Desktop → Settings → Developer → Edit Config).
Client khác (Cursor, VS Code, Windsurf…)
Đa số có mục "add MCP server" nhận lệnh chạy. Dùng:
uv run --project C:/path/to/chatgptimage aigpt-mcp
Server này là stdio — không có HTTP endpoint. Nếu client cần JSON, dán block giống Bước 3.
Tools bạn có
  • generate_image — prompt, aspect, số lượng, ảnh tham chiếu (edit / ghép / theo style), brand color, tiếp tục theo conversation
  • login_status — xem có bao nhiêu account sẵn sàng
